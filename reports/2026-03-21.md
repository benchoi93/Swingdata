- Inline SHAP values (3 models × top features)
- Inline DiD claims (dose-response r, placebo beta)
- Mediation bootstrap CIs (6 outcomes × point + CI)
- Paired comparison Cohen's d values
- Experience/escalation mediation percentages
- Compensation inline claims (switcher counts, STD/ECO DiD betas, max |d|)
- Survival inline claims (HRs, C-index, Schoenfeld rho)
