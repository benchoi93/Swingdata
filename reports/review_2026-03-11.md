### Suggested Research Directions

1. **Staggered Speed Governance Rollout: Heterogeneity-Robust DiD** (Feasibility: HIGH)
   - Method: Apply the Callaway and Sant Anna (2021) or Sun and Abraham (2021) heterogeneity-robust DiD estimator to the 52-city panel. The current paper uses a single system-wide treatment date (Dec 2023), which avoids TWFE bias. However, each city effective treatment intensity (TUB share drop) varies, enabling a continuous-treatment extension via the de Chaisemartin and D Haultfoeuille (2020) estimator. This directly addresses the limitation noted in discussion.tex line 56. Bergh et al. (2025) provide a methodological comparison, using staggered rollout across Swedish municipalities for crash outcomes.
   - Data needed: `data_parquet/v2/city_month_panel_v2.parquet` (already available, 549 obs). No new data required.
   - Expected finding: The heterogeneity-robust estimator should confirm the TWFE result since treatment is simultaneous. The continuous-treatment extension would reveal whether the dose-response relationship (r=0.621 for harsh decel) is linear or shows threshold effects -- e.g., do cities need >40% TUB reduction to see meaningful safety gains?
   - Target venue: AMAR or Transportation Research Part A (policy focus)
   - Connection to current work: Directly addresses the Goodman-Bacon (2021) limitation already cited in discussion.tex. Extends the dose-response analysis from a simple correlation to a formal causal estimator.

2. **Within-Trip Speed Sequence Anomaly Detection via 1D-CNN** (Feasibility: HIGH)
   - Method: Train a 1D convolutional neural network (or lightweight Transformer encoder) on raw within-trip speed vectors to classify trips as "contains harsh event" vs. "smooth trip." The 10-second GPS interval produces variable-length sequences (typically 10-100 time steps). Use 1D-CNN with global max-pooling to handle variable lengths. Compare against the current LightGBM baseline (AUC=0.734 for harsh event classification using 15 engineered features). No prior study has applied deep learning directly to within-trip speed profiles for micromobility safety classification.
   - Data needed: Raw speed arrays from `routes_all.parquet` (speeds column, already parsed for 44.1M trips). The trip_modeling.parquet already has the labels (harsh_accel_count, harsh_decel_count).
   - Expected finding: Modest AUC improvement (0.74 to 0.78-0.82). The more interesting finding would be identifying specific temporal motifs (e.g., rapid acceleration followed by sustained high speed followed by sudden deceleration) that predict harsh events but are not captured by summary statistics. Connects to PI expertise in TrajGAIL and sequence modeling.
   - Target venue: TR Part C (methodological contribution) or IEEE T-ITS (safety application). Shorter version at ITSC 2026.
   - Connection to current work: The SHAP analysis (Phase 1.4) showed that log-distance and cruise fraction are important beyond mode, but these are all scalar summaries. A sequence model would test whether temporal dynamics add value.

3. **Graduated Mode Access Policy Simulation via Counterfactual Matching** (Feasibility: MEDIUM)
   - Method: Simulate the graduated mode access policy recommended in discussion Section 5.5 using propensity score matching. For each user who adopted TUB before trip N (where N varies: 10, 20, 50), find a matched control who adopted TUB after trip N but had similar covariates at trip N (age, city, trip frequency, pre-N harsh event rate). Compare downstream safety outcomes (harsh events at trips N+1 to N+50) between early and delayed TUB adopters. This is a retrospective counterfactual: "what if this user had been restricted to STD for their first N trips?"
   - Data needed: User-trip sequences from `data_parquet/v2/trip_modeling.parquet` (19.5M trips, 1M users). Would need to compute per-user TUB adoption timing and pre-adoption covariates. All data already available.
   - Expected finding: Users who adopted TUB early (trips 1-10) would show higher downstream harsh event rates than matched users who adopted later (trips 30-50), even after matching on pre-adoption behavior. The survival analysis already shows median time-to-first-harsh of 2 trips for TUB users; the counterfactual matching would estimate whether delay changes the trajectory.
   - Target venue: Accident Analysis and Prevention (AAP) or AMAR (follow-up paper)
   - Connection to current work: Directly operationalizes the graduated mode access policy recommendation (discussion Section 5.5). The concave TUB adoption curve (results Section 4.4, line 215) provides the empirical basis -- the critical window is trips 1-30.
