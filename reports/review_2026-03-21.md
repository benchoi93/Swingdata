### Suggested Research Directions

1. **Causal Forest for Heterogeneous Treatment Effects of TUB Ban** (Feasibility: HIGH)
   - Method: Apply generalized random forests (Athey, Tibshirani, Wager 2019) to estimate conditional average treatment effects (CATE) of the Dec 2023 TUB ban across city-level covariates (city size, pre-ban TUB share, road network density, geographic region). The current TWFE DiD estimates a single average effect; causal forests would reveal which cities benefited most and why.
   - Data needed: city_month_panel_v2.parquet (already available, 549 obs). City-level covariates can be derived from existing OSM networks (road density, network centrality) and trip_modeling.parquet (pre-ban behavioral profiles). No new data collection needed.
   - Expected finding: Treatment effect heterogeneity is substantial -- cities with higher pre-ban TUB share and denser road networks see larger safety improvements. This would extend the dose-response analysis (r=0.567) from a linear relationship to a nonparametric heterogeneity map. Recent work by Cicchino et al. (2024, IIHS) on e-scooter injuries found heterogeneous effects by infrastructure type, suggesting city-level moderators matter.
   - Target venue: Transportation Science or Journal of Causal Inference
   - Connection to current work: Directly extends Block 2 (TWFE DiD) from homogeneous to heterogeneous treatment effects. The dose-response correlation (r=0.567) already hints at heterogeneity; causal forests would formalize this.

2. **Sequence-to-Risk Classification Using Transformer on Raw Speed Profiles** (Feasibility: HIGH)
   - Method: Train a lightweight Transformer encoder (4 layers, 64-dim) on raw within-trip speed sequences (variable-length, ~10s intervals) for binary classification: risky trip (any harsh event OR speed CV > 0.3) vs. safe trip. Compare against the current LightGBM (AUC=0.905) which uses hand-crafted features. Use attention weights to identify which temporal segments of a trip are most predictive of risk. Apply positional encoding adapted for irregular time series.
   - Data needed: speeds column from routes_all.parquet (variable-length arrays, already available) plus labels from trip_indicators_v2.parquet. Sample 500K trips for training, 100K for test. No new data needed.
   - Expected finding: The Transformer should match or slightly exceed LightGBM AUC (~0.91-0.92) while providing temporal interpretability. Attention maps will likely show that the first 30-60 seconds (acceleration phase) and segments near intersections are most predictive. If performance gain is marginal, this validates that mode label alone is a sufficient statistic for risk prediction -- a powerful policy finding (you only need to know the mode, not monitor the full trip).
   - Target venue: TR Part C or NeurIPS Workshop on Machine Learning for Autonomous Driving
   - Connection to current work: Extends Phase 1 SHAP analysis by asking whether raw speed dynamics contain information beyond the hand-crafted features. The current finding that TUB mode SHAP=2.33 (3.6x next feature) suggests mode dominates; sequence models would test whether this dominance holds when given the full signal.

3. **Survival Analysis of Platform Churn After TUB Ban** (Feasibility: MEDIUM)
   - Method: Use the 24-month longitudinal user data (1.82M users) to estimate time-to-churn after the Dec 2023 TUB ban using Cox proportional hazards with time-varying covariates. Define churn as no trip activity for 60+ days. Key predictors: pre-ban TUB fraction (continuous), pre-ban trip frequency, city, user tenure. Test whether heavy TUB users (>50% TUB trips pre-ban) churned at higher rates than light/non-TUB users, which would indicate a demand cost of the safety intervention not captured by the aggregate DiD null result on trip counts.
   - Data needed: user_longitudinal.parquet (1.82M users, already available) plus trip-level dates from routes_all.parquet to construct churn indicators. Needs computation of last-trip-date per user per month, but no external data.
   - Expected finding: Heavy TUB users show 15-25% higher churn hazard in Jan-Mar 2024 compared to non-TUB users, but the effect attenuates by Apr 2024 as remaining users adapt. This would nuance the current Block 2 finding that the TUB ban had no aggregate demand cost -- the demand was preserved in aggregate because churning TUB-heavy users were replaced by new users, but individual-level churn was real.
   - Target venue: AMAR (as an extension of the current paper) or Accident Analysis and Prevention
   - Connection to current work: Directly extends Block 2 (demand DiD null result) and Block 4 (survival analysis) by asking whether the aggregate null masks individual-level selection. The current survival analysis focuses on time-to-first-speeding; this would add time-to-churn as a complementary endpoint with direct policy relevance.
