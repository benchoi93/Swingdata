### Suggested Research Directions

1. **Within-Trip Speed Sequence Classification via 1D-CNN or Transformer** (Feasibility: HIGH)
   - Method: Extract raw speed vectors from GPS data (variable-length time series at approximately 10s intervals). Pad/truncate to fixed length. Train 1D-CNN, LSTM, or lightweight Transformer to classify trips as safe vs. risky (binary: any harsh event or speeding). Compare against the tabular LightGBM baseline (AUC=0.905). Use SHAP on the sequence model to identify which temporal positions (trip start, mid, end) contribute most to risk prediction.
   - Data needed: Speed vectors already available in routes_all.parquet (44.1M trips). Labels derivable from existing harsh_accel_count, max_speed columns. No external data required.
   - Expected finding: Sequence models may capture temporal patterns invisible to tabular features (e.g., gradual acceleration ramp-up preceding harsh events, speed oscillations before speeding episodes). Temporal SHAP could reveal that the first 60 seconds of a trip are most predictive of eventual speeding.
   - Target venue: TR Part C or IEEE T-ITS (sequence modeling + safety application)
   - Connection to current work: Extends the SHAP feature importance analysis (Section 4.3) from static features to dynamic within-trip patterns. The current paper shows TUB mode dominates static prediction; this would test whether within-trip dynamics add predictive power beyond mode selection.

2. **Heterogeneous Treatment Effects of the TUB Ban via Causal Forest** (Feasibility: HIGH)
   - Method: Apply generalized random forests (Athey, Tibshirani and Wager, 2019) to estimate conditional average treatment effects (CATEs) of the Dec 2023 TUB ban. Unit of analysis: city-month or user-month. Treatment: TUB exposure intensity. Covariates for heterogeneity: city size, baseline speeding rate, road network density, cycling infrastructure share. Identify subgroups where the ban was most/least effective.
   - Data needed: city_month_panel.parquet (already exists), road network attributes from OSM (already extracted for 50 cities), cycling infrastructure variable (already computed). All data available.
   - Expected finding: The TUB ban may be most effective in mid-size cities with moderate baseline speeding (where TUB adoption was highest but alternative infrastructure exists). Large cities with dense networks may show smaller effects due to already-lower speeds from congestion. This would refine the current homogeneous TWFE estimate.
   - Target venue: AMAR or Journal of Causal Inference (causal ML + transportation safety)
   - Connection to current work: The current paper estimates an average treatment effect via TWFE DiD. Causal forests would decompose this into heterogeneous effects, directly extending the dose-response analysis (Section 4.4) from linear to nonlinear heterogeneity.

3. **Synthetic Speed Profile Generation via Conditional Diffusion Models** (Feasibility: MEDIUM)
   - Method: Train a conditional denoising diffusion probabilistic model (DDPM) on within-trip speed sequences, conditioned on trip metadata (mode, distance, road class, time of day). Generate synthetic but realistic speed profiles for privacy-preserving data sharing. Evaluate fidelity via distributional metrics (MMD, Frechet distance on speed feature space) and utility (downstream task performance on synthetic vs. real data for speeding prediction).
   - Data needed: Raw speed vectors from routes_all.parquet. Trip metadata already available. No external data needed. Computational cost is moderate (training on a 1M-trip subsample with GPU).
   - Expected finding: Diffusion models should capture the multimodal speed distributions (governed vs. ungoverned) and the temporal structure (acceleration at trip start, cruising mid-trip, deceleration at end). Conditional generation could enable counterfactual analysis -- creating synthetic paired data for causal analysis of what a TUB trip would look like under STD governance.
   - Target venue: NeurIPS or ICML workshop (generative models for transportation), or TR Part C (aligns with PI generative models tutorial paper)
   - Connection to current work: Directly leverages the PI expertise in deep generative models (TrajGAIL, generative tutorial in TR Part C 2025). The current paper documents the behavioral differences between modes; generative models could synthesize mode-counterfactual speed profiles, enabling a new form of causal analysis. This also addresses the privacy concern noted in the Limitations section -- synthetic data could enable open sharing of this proprietary dataset.
