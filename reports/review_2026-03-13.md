## Review: 2026-03-13.md

### Score: B+

A solid research-only deliverable. The land use data source evaluation is thorough, well-structured, and actionable. The empirical OSM coverage tests add real value beyond desk research. However, the lack of a reproducible script for those empirical tests is a significant gap for a project that emphasizes reproducibility.

### Issues Found

1. **[MAJOR] No reproducible script for OSM coverage empirical tests**
   - The report claims specific numbers (4,778 landuse polygons in Seoul, 14.5% trip match rate, 68.3% unclassified buildings, 99.6% within 200m, etc.) but no Python script exists in src/v2/ or anywhere in the repo that produces these numbers.
   - Grep for key constants (4778, 14.5, 68.3) returns zero hits in any .py file.
   - These appear to have been computed interactively (likely in a REPL or notebook) and only recorded in the markdown report.
   - Suggested fix: Save the OSM coverage test code as src/v2/osm_coverage_test.py so results can be reproduced.

2. **[MINOR] Line count off by one**
   - Daily report says land_use_data_research.md is 454 lines. Actual count: 453 lines.
   - Suggested fix: Correct to 453 in the daily report.

3. **[MINOR] Daejeon bounding box area likely inflated**
   - The detailed report states the Daejeon test bbox covers 1,012.8 sq km, but the actual city area of Daejeon is approximately 539 sq km. The bbox appears to extend well beyond city limits.
   - This does not invalidate the coverage finding (9.0% is still low), but the denominator is inflated.
   - Suggested fix: Note that the bbox extends beyond city limits, or use the actual administrative boundary for the area calculation.

4. **[MINOR] Unsourced claim about Korean OSM building coverage**
   - The detailed report states 7.6% of Korean buildings are mapped in OSM without citing a source.
   - Suggested fix: Add a citation (e.g., ohsome dashboard or Geofabrik stats) or qualify as an estimate.

5. **[MINOR] MOLIT data format description inconsistency**
   - The report alternately describes MOLIT zoning data as CSV/SHP and later as requiring cadastral boundary polygons. The actual format from MOLIT is typically SHP or GeoJSON via NSDI.
   - Suggested fix: Clarify the expected download format and whether boundary polygons come bundled or must be obtained separately.

6. **[MINOR] Kakao API rate limit not verified**
   - The report recommends Kakao POI queries across 8,144 H3 hexes but does not confirm the API rate limit or whether bulk queries are permitted under the free tier.
   - Suggested fix: Check Kakao developer documentation for rate limits before recommending this approach.

### Suggested Research Directions

1. **Land Use as Heterogeneous Treatment Effect Modifier** (Feasibility: HIGH)
   - Method: Once land use data is integrated (any source), estimate mode x land_use interaction terms in the individual FE models. Specifically: does TUB mode have a LARGER speed-increasing effect in commercial areas (higher ambient speed) vs residential (lower ambient speed)? Use triple-difference: mode x land_use x post_ban in the DiD framework.
   - Data needed: trip_modeling.parquet + land use classification at trip origin (H3 hex level). WorldPop population density is the minimum viable proxy (already identified as 30-min integration). MOLIT zoning is ideal.
   - Expected finding: TUB mode effects are amplified in low-density suburban areas where road geometry permits higher speeds, but attenuated in dense urban cores where congestion mechanically limits speed regardless of mode. This would explain some of the city-level heterogeneity in dose-response (r=0.567).
   - Target venue: AMAR (extends current paper) or Transportation Research Part D (built environment focus)
   - Connection to current work: Directly extends Phase 7C. The FE infrastructure is already built (pyfixest, 2M sample). Adding land use interactions requires only a new column and re-running existing specifications.

2. **Spatial Spillover of Speeding Behavior via Spatial Durbin Model** (Feasibility: HIGH)
   - Method: Construct H3-hex-level speeding prevalence panel (hex x month, Feb-Nov 2023). Estimate Spatial Durbin Model (SDM) with spatially lagged dependent variable AND spatially lagged TUB share. Test whether high-TUB hexes increase speeding in neighboring hexes (spatial contagion) or whether the effect is contained locally. Use queen contiguity or k-nearest-hex weights. Already have Moran I results (Seoul 0.213, Daegu 0.712) confirming spatial autocorrelation.
   - Data needed: data_parquet/spatial/*.parquet (H3 hex aggregates, already computed). Need to add monthly dimension. OSM networks already available for 50 cities. PySAL/libpysal already installed.
   - Expected finding: Positive spatial lag of TUB share (rho > 0) -- areas adjacent to high-TUB hexes also show elevated speeding, even after controlling for own-hex TUB share. This suggests behavioral contagion or infrastructure-mediated spillover (e.g., wide roads that span multiple hexes).
   - Target venue: Journal of Transport Geography or Spatial Statistics
   - Connection to current work: Builds on the spatial analysis already done (Moran I, Gi* hot spots from Phase 9). The SDM would formalize what the hot spot maps suggest qualitatively.

3. **Hidden Markov Model for Rider Behavioral State Transitions** (Feasibility: MEDIUM)
   - Method: For users with 20+ trips, model the sequence of trip-level behavioral indicators (speeding, harsh events, speed CV) as emissions from a latent HMM with K=3-4 states (e.g., cautious, normal, aggressive, reckless). Estimate transition probabilities as functions of covariates (TUB adoption, experience rank, time of day). Key question: is TUB mode adoption a CAUSE of transitioning to riskier states, or does it CO-OCCUR with a pre-existing transition? Use the 24-month longitudinal depth (user_longitudinal.parquet, 1.82M users).
   - Data needed: user_longitudinal.parquet (already computed) + trip-level indicators ordered by user and timestamp. May need to compute trip-level state features for the full 44.1M trips (currently only 19.5M scooter trips in v2 modeling set). hmmlearn package (not currently installed but pip-installable).
   - Expected finding: Three-state model (safe/moderate/aggressive) with TUB adoption strongly associated with transition from safe to moderate state (not directly to aggressive). The escalation pathway (Phase 4) already shows this pattern at the aggregate level; HMM would formalize it at the individual level and distinguish causal ordering from co-occurrence.
   - Target venue: Transportation Research Part C (methodological contribution) or NeurIPS Workshop on ML for Transportation
   - Connection to current work: Directly formalizes the Phase 4 escalation pathway findings. The current survival analysis (HR=5.73 for ever_tub) and experience curves (TUB adoption 23% to 69.5%) are suggestive but do not model the full state-transition dynamics. HMM would provide a richer picture of individual behavioral trajectories.

### Summary Assessment

This is a well-executed research task that provides actionable intelligence for the PI decision at Phase 7C.2. The evaluation of 11+ data sources is comprehensive, and the empirical OSM testing adds credibility beyond desk research. The main weakness is reproducibility: the empirical numbers should be backed by a saved script. The recommendations are well-ranked and include realistic effort estimates. The report correctly identifies the tradeoff between data quality (MOLIT zoning) and implementation effort (WorldPop density), giving the PI clear options.

The project is in good shape overall. With Phases 0-6 and 7A-7B complete, the paper has a solid analytical foundation. The land use controls (Phase 7C) are the last major addition before the paper is ready for internal review.
