### Suggested Research Directions

1. **Geofencing Compliance via Regression Discontinuity Design** (Feasibility: HIGH)
   - Method: Many Korean cities enforce lower speed limits (15 km/h) in designated slow zones (school zones, pedestrian areas). If zone boundaries can be identified from OSM or MOLIT data, trips crossing a zone boundary create a sharp spatial discontinuity. Apply a geographic RDD: compare speeds in 50m bands on either side of the boundary. The running variable is distance to the zone boundary (signed: negative inside, positive outside). Estimate the local average treatment effect (LATE) of geofencing on speed and harsh event counts. Bandwidth selection via Imbens-Kalyanaraman optimal bandwidth. Placebo test: use random boundary shifts.
   - Data needed: trip GPS sequences (already in routes_all.parquet), OSM boundaries for school/slow zones (available via Overpass API queries for highway=living_street or maxspeed=15 tags), trip_indicators.parquet for outcome variables. The osm_coverage_test.py script already demonstrates the Overpass API workflow.
   - Expected finding: Speed drops sharply at zone boundaries (5-8 km/h discontinuity), but the effect decays rapidly beyond 100m, suggesting compliance is local and not internalized. Harsh deceleration events spike AT the boundary (braking to comply), creating a safety paradox where the geofence itself generates risk.
   - Target venue: AMAR or Journal of Safety Research (spatial causal identification is methodologically novel for micromobility)
   - Connection to current work: Extends the speed governance analysis from mode-level (TUB/STD/ECO) to spatial governance. Uses the same GPS trajectory infrastructure and harsh event definitions. The DiD framework (Phase 11) already demonstrates causal identification skills; RDD adds a complementary identification strategy.

2. **Counterfactual Speed Distribution Estimation via Quantile Treatment Effects** (Feasibility: HIGH)
   - Method: The current paper estimates mean treatment effects (TUB mode shifts mean speed by +X km/h). But the DISTRIBUTIONAL effect matters more for safety: does TUB mode shift the entire distribution rightward, or does it specifically inflate the upper tail? Estimate unconditional quantile treatment effects (UQTEs) using the Firpo-Fortin-Lemieux (2009) recentered influence function (RIF) regression at quantiles tau = {0.10, 0.25, 0.50, 0.75, 0.90, 0.95, 0.99}. Compare TUB vs STD conditional on road class and time of day. The individual FE infrastructure (pyfixest) can be adapted for quantile FE via the Machado-Santos Silva (2019) method.
   - Data needed: trip_modeling.parquet (already has mean_speed, mode, road class, user_id). Need to compute within-trip speed quantiles (P10, P25, P50, P75, P90, P95, P99) from the raw speed vectors -- feasible via DuckDB on routes_all.parquet. Approximately 2 hours of computation.
   - Expected finding: TUB mode has a LARGER effect at upper quantiles (tau=0.90-0.99) than at the median, confirming that speed governors disproportionately affect the dangerous tail of the distribution. The effect at tau=0.10 may be near zero (slow trips are slow regardless of mode). This would quantify the safety benefit more precisely than mean-based estimates.
   - Target venue: Transportation Research Part C (methodological contribution on distributional causal effects) or Econometrica (if the identification is clean enough)
   - Connection to current work: Directly extends the cross-sectional mode comparisons (Phase 1) from mean to distributional effects. The threshold sensitivity analysis already hints at distributional differences (30 km/h threshold: 0.2% speeding rate). QTE would formalize this and provide the full counterfactual distribution.

3. **Transfer Learning for City-Specific Speeding Prediction with Limited Data** (Feasibility: MEDIUM)
   - Method: The current LightGBM model (AUC=0.905) is trained on pooled data from all 52 cities. But city-level heterogeneity is substantial (TUB OR ranges 70-207 across cities, dose-response r=0.567). Train a base model on the 10 largest cities (80% of trips), then fine-tune on each of the remaining 42 cities using only 1,000-5,000 trips. Compare: (a) pooled model applied directly, (b) city-specific model trained from scratch, (c) transfer learning with frozen base layers + fine-tuned head. Use MAML (model-agnostic meta-learning) for few-shot adaptation. Evaluate via AUC, calibration (Brier score), and SHAP feature importance stability across cities.
   - Data needed: trip_modeling.parquet (already has all features). Need to split by city and create city-specific train/test sets. The 52-city structure with varying sizes (Seoul ~500K trips vs small cities ~5K trips) creates a natural few-shot learning scenario. No new data computation required.
   - Expected finding: Transfer learning outperforms both pooled and city-specific models for small cities (n < 10,000 trips) by 3-5 AUC points. SHAP analysis reveals that TUB mode importance is universal (transfers well) but road class effects are city-specific (require fine-tuning). This has practical implications: new city deployments can use pre-trained models with minimal local calibration.
   - Target venue: NeurIPS Workshop on ML for Transportation or IEEE T-ITS (applied ML contribution)
   - Connection to current work: Builds directly on the SHAP/LightGBM analysis (Phase 8.4, AUC=0.905) and the city-level heterogeneity findings (Phase 11 dose-response). The PI has expertise in transfer learning for transportation (Jin et al. 2022 TR-C map-matching paper), making this a natural methodological extension.
